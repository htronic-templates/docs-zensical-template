# Readme

This is a documentation template using zensical
This is a successor to mkdocs material

  * https://zensical.org

visible at:

  * https://htronic-templates.github.io/docs-zensical-template/

## Plugins of Interest

  * mkdocstrings
    https://zensical.org/docs/compatibility/mkdocs/plugins/?h=mkdocstrings#mkdocstrings
  * mkdocstrings-python
    Handler for the above mkdocstrings for python
